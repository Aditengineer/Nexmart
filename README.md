# Nexmart - E-Commerce Application

A modern e-commerce app built with React, Vite, and React Router.

## Quick Deploy to Vercel

1. Go to https://vercel.com/new
2. Import 'Nexmart' repository
3. Click Deploy
4. Your app is live!

## Features

- 50+ React components
- 36 mock products
- Shopping cart
- Checkout flow
- Authentication
- Search & filter
- Order history
- Responsive design
